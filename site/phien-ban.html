Phiên bản

Những điểm mới trong từng bản. Chỉ bản mới nhất được tải về. Mọi bản đều do GitHub tự build từ mã nguồn.

Ký số: Zenlo đang xin chứng chỉ ký số miễn phí của SignPath Foundation; khi được duyệt, bộ cài sẽ được ký (Free code signing provided by SignPath.io, certificate by SignPath Foundation). Các bản tới nay chưa được ký. Xem Code signing policy.

🔔 Nhận thông báo khi có bản mới

Theo dõi trên GitHub

Mở trang mã nguồn, bấm Watch → Custom → tick Releases → Apply. GitHub sẽ gửi e-mail mỗi khi có bản mới. Cần tài khoản GitHub (miễn phí).

Thêm địa chỉ dưới đây vào ứng dụng đọc tin RSS bạn đang dùng (Feedly, Inoreader…).
